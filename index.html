발표 대본

발표 사이트(site/index.html) 슬라이드 순서와 같다. 본편 21장 + 질문 대비 부록 7장.
예상 시간: 본편 약 18–20분 (슬라이드별 시간은 대략).
15분 발표일 때 권장 배분: 1·2부 3분 / 3부 모델 4분 / 4부 파이프라인 3분 / 5부 결과 3분 / 6부 한계·추가 실험 2분.
줄일 곳: 2번 요약은 한 문장만, 4번 배경과 14번 앙상블은 핵심만, 17·18번 추가 실험은 18번 결과만, 19번 재현은 생략 가능. 부록은 질문 대응용.
용어 설명은 용어정리.txt 참고.

숫자 출처

  • 모델 구조·학습 설정: flyvis 코드와 사전학습 모델 설정 파일에서 직접 확인
  • 비교 대상 세포 유형 수: flyvis에 들어 있는 비교용 실측 데이터(groundtruth_utils)에서 직접 셈
  • 재현·추가 실험 숫자: 이 저장소에서 직접 계산 (results/summary.md)

파란 [번호]를 누르면 용어 설명이 뜹니다. 각 구간 오른쪽 위 "슬라이드 열기"는 해당 슬라이드로 이동합니다.

1번

표지

30초슬라이드 열기 ↗

발표할 논문은 2024년 Nature에 실린 "Connectome-constrained networks predict neural activity across the fly visual system"입니다. 초파리의 뇌 배선도, 즉 커넥톰[1]으로 구조를 정한 신경망을 학습시켜서 초파리 시각계 뉴런의 활동을 예측한 연구입니다.
순서는 논문을 고른 이유, 독창성, 사용한 모델, 학습 파이프라인, 결과, 그리고 한계와 극복 아이디어 순으로 진행하겠습니다.

개요

2번

논문 요약

1분슬라이드 열기 ↗

먼저 논문을 한 문장으로 요약하면, 실제 초파리 시각계의 연결 구조를 RNN[2]의 구조적 제약으로 쓰고, 광류[3] 예측이라는 지도학습[4] 과제로 학습한 다음, 학습된 뉴런들의 반응이 실제 생물학적 관측과 얼마나 맞는지 검증한 연구입니다.
문제는 뉴런 측정 데이터 없이 개별 뉴런의 반응 특성을 예측할 수 있느냐이고, 모델은 커넥톰[1] 기반 RNN, 학습은 광류 예측 지도학습과 BPTT[5], 평가는 실제 측정과의 비교와 50개 모델 분석입니다.
머신러닝 관점에서 핵심 개념은 귀납적 편향[6], 파라미터 공유[7], RNN, BPTT, 일반화[8] 다섯 가지이고, 발표 중에 이 순서대로 나옵니다.

1부. 논문 선택 이유

3번

논문을 고른 이유

1분슬라이드 열기 ↗

오픈소스 프로젝트들을 보다가 초파리 뇌 전체의 연결 지도, 커넥톰[1]이 공개됐다는 걸 알게 됐습니다. 그 지도를 가지고 초파리 뇌 모델에 게임을 시키는 것 같은 실험들이 진행되고 있었고, 관련 논문을 찾다가 이 논문을 보게 됐습니다.
읽어 보니 수업에서 배운 내용과 겹치는 부분이 많았습니다. 오른쪽 표처럼 모델 자체가 ReLU를 쓰는 RNN[2]이고, 역전파[9]와 경사 하강법[10]으로 학습하고, CNN[11]의 가중치 공유와 같은 아이디어를 쓰고, 검증 손실[12]로 모델을 고릅니다. 마지막 줄의 EEG[13]와 신호처리는 뒤에서 한계를 다룰 때 연결하겠습니다.

2부. 독창성

4번

배경

1분 30초슬라이드 열기 ↗

커넥톰[1]은 뉴런끼리 연결되어 있는지, 시냅스가 몇 개인지를 알려 줍니다. 흥분성인지 억제성인지는 세포 유형[14]의 신경전달물질 정보로 추정해서 붙입니다. 그런데 뉴런이 실제로 어떻게 활동하는지 계산하려면 각 뉴런이 얼마나 빨리 반응하는지, 쉬고 있을 때 전압은 얼마인지, 연결이 실제로 얼마나 센지도 알아야 합니다. 이건 배선도만 봐서는 알 수 없습니다.
지금까지는 이 값을 채우려면 세포마다 직접 전극이나 칼슘 이미징[15]으로 측정하거나, 측정한 데이터에 모델을 맞추는 방법을 썼습니다. 하지만 측정은 세포 유형 하나하나 해야 하고, 작은 세포는 기록 자체가 어렵습니다. 이 모델에 들어간 세포 유형 57개(광수용체[16] 제외, 모델 기준) 중에서 밝음과 어두움 중 무엇에 반응하는지 실험으로 알려진 것도 24개뿐입니다.
그래서 이 논문은 측정 없이 커넥톰과 이 회로가 하는 일만으로 개별 뉴런의 활동을 예측할 수 있는지를 묻습니다.

5번

기존 방법과 비교

1분 30초슬라이드 열기 ↗

기존 접근 두 가지와 비교했습니다.
첫 번째는 측정 데이터에 맞춘 모델입니다. 학습에 측정 데이터가 필요하고, 측정된 세포에만 쓸 수 있습니다.
두 번째는 과제 기반 딥러닝입니다. 예를 들어 물체 인식을 학습한 CNN[11]의 내부 표현을 원숭이 시각피질 활동과 비교하는 연구들입니다. 측정 데이터 없이 학습한다는 점은 이 논문과 같지만, CNN의 유닛이 실제 어떤 뉴런인지 대응이 없어서 뇌 영역 전체 수준으로만 비교할 수 있습니다.
이 논문의 모델은 구조 자체가 커넥톰[1]이라서 모델 뉴런 하나가 실제 뉴런 하나에 대응합니다. 그래서 세포 유형[14] 단위로 실험 결과와 비교할 수 있고, 아직 측정되지 않은 세포에 대해서도 예측을 할 수 있습니다.
마지막 줄이 일반 딥러닝과의 가장 큰 차이입니다. 일반 딥러닝 모델은 범용 구조에서 데이터로부터 표현을 학습하는데, 이 논문은 실제 신경 연결 구조라는 사전 지식을 모델 구조 자체에 넣었습니다.

6번

독창성

1분슬라이드 열기 ↗

정리하면 독창성은 네 가지입니다.
첫째, 뉴런 측정 데이터를 학습에 쓰지 않았습니다. 구조는 커넥톰[1]으로 고정하고 나머지는 움직임 감지[17] 과제로 학습했습니다.
둘째, 모델 뉴런과 실제 뉴런이 일대일로 대응합니다.
셋째, 규모입니다. 세포 유형[14] 64개, 뉴런 약 4만 6천 개, 연결 약 151만 개로 시각엽[18]의 움직임 경로 전체를 한 모델로 학습했습니다.
넷째, 같은 설정으로 모델을 50개 학습해서, 모델끼리 예측이 일치하는지로 예측을 얼마나 믿을 수 있는지 판단합니다.

3부. 모델

7번

DMN

2분슬라이드 열기 ↗

논문의 모델 이름은 DMN[19], Deep Mechanistic Network입니다. 위의 식이 뉴런 하나의 전압이 시간에 따라 어떻게 변하는지를 나타냅니다. 전압은 휴지 전위[20]로 돌아가려는 성질이 있고, 연결된 다른 뉴런들의 출력에 가중치를 곱해 더한 값과 외부 입력의 영향을 받습니다. τ는 반응 속도를 정하는 시간 상수[21]이고, 아래 첨자 c(i)는 뉴런 i가 속한 세포 유형[14]이라는 뜻입니다. 시간 t와 헷갈리지 않게 c로 표기했습니다.
이것을 RNN[2]과 대응시키면 아래 표와 같습니다. 은닉 상태[22]가 뉴런 전압이고, 순환 가중치 행렬[23]이 커넥톰[1]입니다. 활성화 함수[24]는 ReLU, 편향은 휴지 전위입니다. 연속시간 식을 20밀리초 간격으로 쪼개서 한 단계씩 계산하기 때문에, 시간 축으로 펼친 RNN과 같은 구조가 됩니다.
오른쪽은 고정 값과 학습 값입니다. 연결 여부와 시냅스 개수는 커넥톰에서, 흥분성·억제성 부호는 신경전달물질 정보에서 가져와 고정합니다. 학습하는 값은 세포 유형별 시간 상수 65개, 휴지 전위 65개, 연결 종류별 시냅스 세기 배율 604개로, 모두 734개입니다. 세포 유형은 64개인데 65개인 이유는 모델에서 CT1 세포를 두 구획으로 나눠 따로 다루기 때문입니다. 그리고 734개는 DMN만의 파라미터이고, 디코더[25]의 파라미터 7,427개가 따로 있어서 둘을 함께 학습합니다.

8번

이 모델을 사용한 이유

1분 30초슬라이드 열기 ↗

일반 RNN[2]이라면 연결 약 151만 개마다 가중치를 따로 학습해야 합니다. DMN[19]은 같은 세포 유형[14]끼리 값을 공유해서 734개만 학습합니다. 겹눈[26]의 721개 기둥마다 같은 회로가 반복되기 때문에 가능한 일이고, CNN[11]이 이미지의 모든 위치에 같은 필터를 쓰는 것과 같은 원리입니다. 이렇게 구조에 대한 가정을 미리 넣는 것을 귀납적 편향[6]이라고 합니다.
이렇게 하면 파라미터가 적어서 과적합[27]이 줄고, 학습된 값이 세포 유형별 시간 상수[21]처럼 생물학적인 의미를 가지고, 모델 뉴런이 실제 뉴런과 대응하니까 세포 단위로 검증할 수 있습니다.
RNN을 쓴 이유는 뉴런의 현재 전압이 이전 시점의 전압과 다른 뉴런들의 이전 출력에 의존하기 때문입니다. 입력을 한 번 통과시키고 끝나는 피드포워드 신경망[28]은 이런 시간에 따른 상태 변화를 표현하지 못합니다. 특히 움직임 감지[17]는 이웃한 위치의 신호가 어떤 순서로, 얼마의 시간 차이를 두고 들어오는지를 계산하는 것이라 순환 구조가 꼭 필요합니다.
ReLU는 전압이 일정 수준 이상일 때만 신호를 전달하는 시냅스의 성질을 단순하게 표현한 것입니다.

9번

디코더

1분슬라이드 열기 ↗

DMN[19]의 출력 세포들의 전압을 읽어서 광류[3], 즉 화면의 각 위치가 어느 방향으로 얼마나 빨리 움직이는지를 예측하는 부분이 디코더[25]입니다. 육각 합성곱[29] 층 두 개로 된 작은 CNN[11]입니다.
입력은 출력 세포 유형[14] 34개의 전압이고, 학습 파라미터[30]는 7,427개입니다. 디코더를 작게 만든 이유는, 디코더가 크면 움직임 계산을 디코더가 대신해 버리기 때문입니다. 층 2개, 채널 8개로 제한해서 계산을 DMN 쪽이 맡도록 했습니다.
겹눈[26]이 육각 격자[31]라서 정사각 필터에 육각 모양 마스크를 씌워 합성곱을 하고, BatchNorm[32]과 Dropout[33]을 씁니다.

4부. 파이프라인

10번

학습 파이프라인

1분 30초슬라이드 열기 ↗

학습 데이터는 Sintel이라는 애니메이션 영화 데이터셋입니다. 각 장면에 대해 정답 광류[3]가 주어져 있습니다.
영상을 겹눈[26] 구조에 맞게 721개 육각 픽셀로 바꾸고, 19프레임씩 잘라서 50Hz로 넣습니다. 뒤집기, 회전, 밝기와 대비 변화, 잡음 같은 데이터 증강[34]을 합니다.
순전파는 광수용체[16] 입력에서 DMN[19] 시뮬레이션, 디코더[25]를 거쳐 광류를 예측합니다. 손실은 예측 광류와 정답 광류의 L2 거리[35]에, 뉴런 활동이 비정상적으로 커지지 않게 하는 정규화 항[36]을 더한 것입니다.
시간 축으로 펼친 역전파[9], BPTT[5]로 기울기를 구하고 Adam[37]으로 갱신합니다. 배치 4로 25만 번 반복합니다.
학습에 쓰지 않은 fold의 검증 손실[12]로 체크포인트[38]를 고르고, 같은 설정으로 50개를 학습해 검증 손실로 순위를 매깁니다. 마지막으로 학습에 쓰지 않은 실제 뉴런 측정 결과와 비교합니다. 이때 모델을 측정 결과에 다시 맞추는 과정은 없습니다.

11번

파이프라인의 특징

1분슬라이드 열기 ↗

머신러닝 관점에서 세 가지를 짚겠습니다.
첫째, 지도학습[4]입니다. 입력 영상과 정답 광류[3]로 손실을 계산하고 BPTT[5]로 DMN[19] 파라미터를 갱신합니다. 중요한 건 실제 뉴런 전압을 정답으로 쓰지 않는다는 점입니다. 원래 관심 있는 것과 다른 과제로 학습하는 대리 과제[39] 방식입니다.
둘째, 일반화[8]입니다. 평가 데이터가 학습 데이터와 종류부터 다릅니다. 학습은 영화 장면과 광류, 평가는 실험실 자극과 실제 뉴런 반응입니다. 학습 분포 밖에서의 일반화를 확인하는 셈입니다.
셋째, 같은 설정으로도 모델마다 결과가 다르기 때문에 모델을 골라야 하는데, 뉴런 데이터로 고르면 테스트 데이터를 미리 보는 셈이라 과제 검증 손실[12]로 고릅니다.

5부. 결과

12번

평가 방법

1분 30초슬라이드 열기 ↗

학습된 모델에 실험실에서 쓰는 자극을 넣고, 세포 유형[14]별 반응을 실제 실험 결과와 비교했습니다. 비교 항목은 세 가지입니다.
첫째는 ON[40]/OFF 극성입니다. 원형 빛을 깜빡여서 밝아질 때 반응하는 세포인지 어두워질 때 반응하는 세포인지를 봅니다. 실험으로 알려진 세포 유형은 24개입니다.
둘째는 방향 선택성[41]입니다. 밝거나 어두운 가장자리를 여러 방향으로 움직여서 특정 방향에만 반응하는지를 봅니다. 알려진 유형은 18개로, 방향 선택적인 것이 8개, 아닌 것이 10개입니다.
셋째는 방향 선택적인 T4[42], T5 세포의 방향별 반응 곡선입니다. 2013년 Maisak 등의 실측 곡선과 비교합니다.

(각 실험이 어떻게 진행되는지는 아래 "논문 실험 상세" 참고. 질문이 나오면 설명)

13번

T4/T5 방향 선택성

1분 30초슬라이드 열기 ↗

왼쪽 그래프는 실제로 측정된 T4[42], T5의 방향별 반응입니다. 각도는 움직임 방향, 반지름은 반응 크기입니다. 각각 a부터 d까지 네 하위 유형이 있고, 하위 유형마다 앞에서 뒤, 뒤에서 앞, 위, 아래 중 한 방향에만 크게 반응합니다.
광류[3] 과제로만 학습한 모델에서도 T4, T5가 이와 같은 방향 선택성[41]을 보였습니다. 반대로 실험에서 방향 선택성이 없다고 알려진 Mi1, Tm3 같은 10개 유형은 모델에서도 방향 선택성이 거의 없었습니다.
공개된 모델로 직접 확인해 보니, 방향 선택성 지수[43]의 중앙값이 방향 선택적 유형은 0.52, 그렇지 않은 유형은 0.02였습니다.

14번

앙상블과 모델 선택

1분 30초슬라이드 열기 ↗

같은 설정으로 50개 모델을 학습하면 세포 유형[14]에 따라 모델마다 반응이 다르게 나옵니다. 커넥톰[1]과 과제만으로는 일부 값이 하나로 정해지지 않는다는 뜻입니다.
논문은 세포 유형마다 50개 모델의 반응을 UMAP[44]으로 2차원으로 줄이고 군집화해서, 모델들이 어떤 종류의 해로 나뉘는지 분석했습니다.
그리고 과제 검증 손실[12]이 낮은 모델일수록 실제 측정과 더 일치하는 경향이 있었습니다. 그래서 뉴런 데이터를 보지 않고 과제 성능만으로 모델을 고를 수 있습니다. 아래 흐름처럼 실제 측정 데이터는 맨 마지막 평가에서만 씁니다.

15번

측정되지 않은 세포에 대한 예측

1분슬라이드 열기 ↗

광수용체[16]를 뺀 모델의 세포 유형[14] 57개 중 ON[40]/OFF 성질이 알려진 건 24개이고 33개는 아직 모릅니다.
모델 뉴런이 실제 세포 유형에 대응하기 때문에 이런 세포들의 반응도 예측할 수 있습니다. 앙상블[45] 모델들의 예측이 일치하면 신뢰할 만하고, 엇갈리면 추가 실험이 필요하다고 볼 수 있습니다. 그래서 실험에서 무엇을 먼저 측정할지 정하는 데 쓸 수 있습니다.
결과를 정리하면 오른쪽 네 가지입니다.

6부. 한계와 극복 아이디어

16번

논문의 한계

1분슬라이드 열기 ↗

한계는 네 가지로 봤습니다.
첫째, 세포 단위 활동만 다룹니다. 사람에게서 얻는 EEG[13] 같은 신호는 많은 뉴런의 활동이 섞인 신호인데, 그런 신호에서도 같은 정보를 읽어낼 수 있는지는 다루지 않았습니다.
둘째, 앞에서 본 것처럼 해가 하나로 정해지지 않습니다.
셋째, 스파이크[46]가 없는 단순한 뉴런 모델입니다.
넷째, 광류[3] 하나의 과제로만 학습했습니다.
2번부터 4번은 모델을 다시 학습해야 해서 노트북으로는 어렵고, 1번은 공개된 학습 모델을 그대로 써서 확인할 수 있어서 1번에 대한 아이디어를 실험해 봤습니다.

17번

가상 뇌에서 섞인 신호 디코딩

1분슬라이드 열기 ↗

학습된 모델을 고정하고 신경 활동을 기록하는 장치로 썼습니다. 같은 뇌에서 세 종류의 신호를 만들었습니다. A는 세포 유형[14]별 전압 평균 65채널로, 특정 세포를 골라 기록하는 경우입니다. B는 세포 유형을 구분하지 않고 눈을 4구역으로 나눠 더한 4채널과, 전체를 더한 1채널로, EEG[13] 전극 4개와 1개에 해당합니다.
각 신호로 막대의 움직임 방향 8개를 분류했습니다. 자극 48개에 측정 잡음[47]을 20번씩 더했고, 처음 보는 속도로 테스트하도록 속도 기준으로 교차검증[48]했습니다. 정규화[49]와 특징 선택[50]은 학습 fold 안에서만 해서 데이터 누수[51]를 막았습니다.

18번

디코딩 결과

1분 30초슬라이드 열기 ↗

(슬라이더를 움직이며) 잡음이 신호 크기와 같을 때 정확도는 세포 단위 신호 99.9%, 4채널 84.1%, 1채널 40.3%입니다. 우연 수준[52]은 12.5%입니다. 잡음이 클수록 차이가 커집니다.
특징 선택[50]으로 세포 유형[14]을 하나씩 추가해 보면 3개로 98.1%가 나왔고, 모든 fold에서 T4[42]a와 T5d가 선택됐습니다. 앞에서 본 방향 선택 세포입니다.
채널 수를 4개로 맞춰 비교하면, 특징 선택으로 고른 세포 4개가 99.5%, 4구역 신호가 84.1%, 무작위로 고른 세포 4개가 중앙값 68.6%였습니다. 채널 수보다 어떤 세포를 기록하느냐가 더 중요했습니다.
마지막으로 정답을 섞은 데이터에서 테스트 정답을 보고 특징을 고르면 22.4%가 나와서, 누수가 있으면 관계없는 데이터에서도 정확도가 우연보다 높게 나온다는 것을 확인했습니다.
시뮬레이션 결과이고 EEG[13]를 단순 합으로 만든 것이라 실제 뇌에 그대로 적용할 수는 없습니다. 그리고 이 실험은 신호를 어떻게 기록하느냐에 따라 읽어낼 수 있는 정보량이 달라진다는 것을 보여줄 뿐, 분류 정확도가 높다고 해서 DMN[19]이 생물학적으로 정확하다는 것까지 증명하지는 않습니다.

논문 실험 상세

논문이 학습된 모델을 평가한 실험들. 무엇을 알아보려고, 어떤 자극으로, 어떤 지표를 계산해서, 무엇과 비교했는지 정리. 계산 방식은 공식 코드(flyvis[56]) 기준.

실험 1. 깜빡임 자극 — ON/OFF 극성

  • 목적: 각 세포 유형[14]이 빛이 밝아질 때(ON[40]) 반응하는지, 어두워질 때(OFF) 반응하는지 확인
  • 배경: 초파리 시각계는 밝아짐을 처리하는 ON 경로[57]와 어두워짐을 처리하는 OFF 경로로 나뉨. 세포가 어느 경로에 속하는지는 실험으로 일부만 알려져 있음
  • 자극: 회색 화면(밝기 0.5)을 1초 보여 준 뒤, 화면 중앙에 원형 빛을 1초 동안 밝게(1) 또는 어둡게(0) 바꿈. 원 크기를 달리해서 반복
  • 측정: 각 세포 유형의 중앙 기둥 뉴런 전압
  • 지표: FRI[58] (Flash Response Index) = (밝아질 때 최대 반응 − 어두워질 때 최대 반응) / (두 값의 합). +1에 가까우면 ON, −1에 가까우면 OFF
  • 비교: 극성이 실험으로 알려진 24개 유형(ON 10, OFF 14)과 FRI 부호가 맞는지
  • 의미: 학습에 쓰지 않은 자극에서 세포의 기본 성질을 맞히는지 보는 가장 기초적인 검증

실험 2. 움직이는 가장자리 — 방향 선택성

  • 목적: 각 세포 유형[14]이 특정 방향의 움직임에만 반응하는지 확인
  • 배경: T4[42](밝은 가장자리)와 T5(어두운 가장자리)는 하위 유형 a–d가 각각 한 방향을 담당하는 방향 감지 세포로 알려져 있음. 이 세포들이 생기려면 회로가 신호 간 시간 차이를 계산해야 함
  • 자극: 화면 절반이 밝거나 어두워지는 경계(가장자리)를 12방향(30° 간격)으로, 여러 속도로 이동
  • 측정: 가장자리가 중앙 기둥 근처를 지나는 시간 동안 각 세포 유형의 최대 전압(음수는 0으로 처리)
  • 지표:
  • DSI[43] (Direction Selectivity Index) = 방향별 반응을 그 방향의 벡터로 놓고 더한 벡터의 길이 / 반응의 합. 0이면 모든 방향에 같은 반응, 1이면 한 방향에만 반응
  • 선호 방향[54] = 더한 벡터의 방향
  • 비교:
  • 방향 선택성[41]이 알려진 18개 유형(선택적 8, 비선택적 10)과 DSI 크기
  • T4a–d, T5a–d의 선호 방향과 방향별 반응 곡선을 실측(Maisak et al. 2013)과 비교
  • 의미: 방향 감지는 과제(광류[3])와 직접 관련된 계산이라, 과제 학습만으로 실제와 같은 세포가 생기는지 보는 핵심 실험

실험 3. 앙상블 분석 — 해의 다양성과 모델 선택

  • 목적: 같은 조건으로 학습한 모델들이 같은 해에 도달하는지, 다르다면 어떤 모델을 믿어야 하는지 확인
  • 방법:
  • 같은 설정으로 50개 모델 학습 (학습 과정의 무작위성 때문에 결과가 다름)
  • 세포 유형[14]마다 50개 모델의 자연 영상(Sintel) 반응을 UMAP[44]으로 2차원으로 줄이고, 가우시안 혼합 모델[59]로 군집화. 군집 수(2–5개)는 BIC[60]로 선택
  • 모델별 과제 검증 손실[12]과 실측 일치도의 관계 확인
  • 결과: 세포 유형에 따라 모델들이 몇 개의 해로 나뉨. 과제 손실이 낮은 모델일수록 실측과 더 일치하는 경향
  • 의미: 실측 데이터[61]를 쓰지 않고 과제 성능으로 모델을 고를 수 있다는 근거. 모델 간 일치도가 예측의 신뢰도가 됨

실험 4. 측정되지 않은 세포 예측

  • 목적: 실험으로 아직 기록되지 않은 세포 유형[14]의 성질 예측
  • 방법: 실험 1, 2와 같은 자극을 모든 세포 유형에 적용해 FRI[58], DSI[43] 계산. 앙상블[45] 모델 간 일치 여부 확인
  • 의미: 실험 연구자에게 측정할 가설과 우선순위를 제공

예상 질문과 답

  • 왜 RNN[2]을 썼나요? 피드포워드 신경망[28]으로는 안 되나요?
  • 뉴런의 현재 상태가 이전 시점 상태에 의존해서 시간에 따른 동역학을 표현해야 합니다. 움직임 감지[17]는 신호 간 시간 차이를 계산하는 것이라 순환 구조가 필요합니다.
  • 연결이 151만 개인데 왜 학습 파라미터[30]는 734개인가요?
  • 연결 여부와 시냅스 개수는 커넥톰[1]으로, 흥분/억제 부호는 신경전달물질 정보로 고정하고, 같은 세포 유형[14]끼리 시간 상수[21]와 휴지 전위[20]를, 같은 연결 종류끼리 세기 배율을 공유하기 때문입니다. 파라미터 공유[7]이자 귀납적 편향[6]입니다. 734개는 DMN[19]만의 수이고, 디코더[25] 파라미터 7,427개는 따로 함께 학습합니다.
  • 정답 데이터는 무엇인가요?
  • Sintel 영상의 정답 광류[3]입니다. 실제 뉴런 전압은 학습에 쓰지 않고 평가에만 씁니다.
  • 일반적인 딥러닝 모델과 무엇이 다른가요?
  • 일반 딥러닝은 범용 구조에서 데이터로 표현을 배우지만, DMN은 실제 신경 연결 구조를 모델 구조에 직접 넣었습니다. 그래서 모델 뉴런이 실제 뉴런과 일대일로 대응합니다.
  • 추가 실험은 무엇을 증명하나요?
  • 신호를 섞는 방식에 따라 방향 정보가 얼마나 남는지를 보여줍니다. DMN의 생물학적 정확성을 증명하는 실험은 아닙니다.
  • 커넥톰을 쓰지 않고 일반 RNN으로 학습하면 안 되나요?
  • 일반 RNN은 연결마다 가중치를 따로 배워야 해서 파라미터가 약 151만 개로 늘어나고, 모델 유닛이 실제 어떤 뉴런인지 대응이 없어서 세포 단위 검증이 안 됩니다.
  • 왜 광류를 과제로 썼나요?
  • 이 회로가 시각엽[18]의 움직임 경로이기 때문입니다. 회로가 실제로 하는 일과 가까운 과제를 줘야 실제와 비슷한 해가 나올 것이라는 가정입니다.
  • 모델마다 결과가 다르면 믿을 수 있나요?
  • 그래서 50개 앙상블[45]을 쓰고, 과제 성능으로 모델을 고르고, 모델 간 일치 여부로 신뢰도를 판단합니다. 재현에서도 과제 손실이 낮은 모델일수록 실측과 더 일치했습니다.
  • 디코더가 계산을 대신하지 않나요?
  • 디코더를 층 2개, 채널 8개의 작은 CNN[11]으로 제한해서 움직임 계산을 DMN이 맡도록 했습니다.
  • 추가 실험은 시뮬레이션인데 의미가 있나요?
  • 실제로는 같은 뇌에서 세포 단위 신호와 섞인 신호를 정답과 함께 동시에 얻기 어려워서 시뮬레이션으로 비교했습니다. 결론은 이 모델 안에서의 결론입니다.
  • 왜 로지스틱 회귀[62]를 썼나요?
  • 정보가 신호에 있는지를 보려는 것이라 단순한 선형 분류기를 썼습니다. K-NN[63], 선형 SVM[64]과도 비교했고 차이가 작았습니다(부록 F).
  • 데이터 누수[51]는 어떻게 막았나요?
  • 속도 기준으로 fold를 나눠 같은 자극의 반복 측정이 학습과 테스트에 섞이지 않게 했고, 정규화[49]·특징 선택[50]·하이퍼파라미터[65] 선택은 모두 학습 fold 안에서만 했습니다(부록 D, G).
